# إضافة إشعارات ESP32-S3 لأندرويد

مشروع مستقل لا يعدّل فيرموير اللوحة أو واجهة الويب. يقرأ `http://<IP>/api/status` محليًا كل 3 ثوانٍ، ويصدر إشعارًا عند تغيّر `motion` أو `presence` فقط.

## بناء APK
1. افتح هذا المجلد في Android Studio حديث.
2. انتظر Gradle Sync.
3. من قائمة Build اختر Build APK(s).
4. ثبّت APK واسمح بالإشعارات.
5. اكتب عنوان IP الذي يفتح من الموبايل؛ العنوان الحالي حسب اختبارك `10.211.233.219`.
6. اضغط «تشغيل الإشعارات».

## ملاحظات
- أبقِ الهوت سبوت شغالًا. إذا تغيّر IP عدّله داخل التطبيق.
- لا يحتاج الإنترنت، لكنه يحتاج الاتصال المحلي بين الهاتف واللوحة.
- تظهر إشعارات دائمة أثناء المراقبة؛ هذا طبيعي لخدمة أندرويد في الخلفية.
- اسمح بالإشعارات، واضبط البطارية على «غير مقيّد» إن أوقف النظام التطبيق.
- أول قراءة تهيّئ الحالة فقط؛ التنبيه يبدأ عند تغيّر الحالة بعدها.
- إشعار `presence` يعتمد على قدرة الفيرموير على رصد الوجود؛ التطبيق لا يضيف مستشعرًا أو قدرة كشف جديدة.
- اختبر على هاتفك؛ قيود الخلفية تختلف حسب إصدار أندرويد والشركة.
